## 1. Введение в JavaScript

**JavaScript** — язык программирования, созданный для того, чтобы «оживлять» веб-страницы. Программы на нём называются **скриптами**. Скрипты подключаются прямо к HTML и выполняются автоматически при загрузке страницы.

### Где работает JavaScript

- **В браузере** — для этого есть встроенный движок (V8 в Chrome, SpiderMonkey в Firefox и т. д.).
- **На сервере** — например, в Node.js.
- **На других устройствах** — вплоть до кофеварок и утюгов, если в них встроен движок JS.

### Как работает движок (упрощённо)

1. Движок читает («парсит») скрипт.
2. Преобразует («компилирует») его в машинный код.
3. Запускает машинный код.

### Что умеет JavaScript в браузере

- Добавлять новый HTML-код на страницу, менять существующее содержимое и стили.
- Реагировать на действия пользователя: клики, движения мыши, нажатия клавиш.
- Отправлять сетевые запросы на сервер и загружать данные (технология AJAX).
- Получать и устанавливать cookie, использовать `localStorage`.
- Задавать вопросы посетителю, показывать сообщения.

### Что НЕ может JavaScript в браузере (ограничения безопасности)

- Нет произвольного доступа к файлам на диске и к системным функциям ОС.
- Нет прямого доступа к содержимому других вкладок и сайтов, если они с другого домена (политика одного источника — *Same Origin Policy*).
- Обмен данными с другим сайтом возможен только при его явном согласии (заголовки CORS).

### Что делает JavaScript особенным

- Полная интеграция с HTML/CSS.
- Простые вещи делаются просто.
- Поддерживается всеми основными браузерами и включён по умолчанию.

### Языки «над» JavaScript

Код на других языках компилируется («транспилируется») в JS:

- **TypeScript** — добавляет строгую типизацию.
- **Flow** — тоже типизация, от Facebook.
- **Dart** — самостоятельный язык, может компилироваться в JS.
- **CoffeeScript**, **Brython**, **Kotlin** и др.

## 4. Консоль разработчика

Код может содержать **ошибки**, и важно уметь их видеть. Для этого есть инструменты разработчика в браузере.

### Как открыть

- **Chrome / Firefox / Edge:** клавиша `F12` или `Ctrl + Shift + I` (на Mac: `Cmd + Option + I`).
- Safari: сначала включить меню разработчика в настройках, затем `Cmd + Option + C`.

### Что есть в консоли

- Сообщения об ошибках скрипта (с указанием строки).
- Можно **вводить команды JavaScript** и сразу запускать их по `Enter`.
- Многострочный ввод: `Shift + Enter`.
- Вывод с помощью `console.log()`:

```js
console.log("Привет из консоли!");
```

### Другие вкладки инструментов разработчика

- **Elements** — просмотр и редактирование HTML/CSS на лету.
- **Network** — сетевые запросы.
- **Sources** — отладка кода, точки останова.

## 5. Основы JavaScript

### 5.1. Привет, мир!

#### Тег `<script>`

JavaScript-код вставляется в HTML с помощью тега `<script>`:

```html
<!DOCTYPE HTML>
<html>
<body>
  <p>Перед скриптом...</p>

  <script>
    alert('Привет, мир!');
  </script>

  <p>...После скрипта.</p>
</body>
</html>
```

Тег можно поместить в любое место документа. Браузер встретит его, выполнит код и продолжит обработку страницы.

> Устаревшие атрибуты `type` и `language` сейчас не нужны.

#### Внешние скрипты

Если код большой, его выносят в отдельный файл и подключают через `src`:

```html
<script src="/path/to/script.js"></script>
```

Можно указать и полный URL:

```html
<script src="https://cdn.example.com/lib.js"></script>
```

**Преимущества отдельных файлов:** браузер кэширует их, поэтому они скачиваются один раз.

> Если указан `src`, содержимое внутри тега `<script>` **игнорируется**.

### 5.2. Структура кода

#### Инструкции

**Инструкции** — синтаксические конструкции и команды, выполняющие действия. Разделяются точкой с запятой:

```js
alert('Привет'); alert('Мир');
```

Обычно каждую инструкцию пишут на новой строке:

```js
alert('Привет');
alert('Мир');
```

#### Точка с запятой

Точку с запятой *часто можно опустить* — JS добавит её автоматически, если есть перевод строки (**автоматическая вставка точки с запятой**). Но бывают случаи, когда это работает неверно:

```js
alert(3 +
1
+ 2);
```

Здесь всё работает ожидаемо, но в других ситуациях возможны ошибки. **Рекомендуется всегда ставить `;`.**

#### Комментарии

Комментарии пояснят, что и зачем делает код.

- **Однострочные** — начинаются с `//`:

```js
// Этот комментарий занимает всю строку
alert('Привет');

alert('Мир'); // Этот комментарий следует за инструкцией
```

- **Многострочные** — между `/* ... */`:

```js
/* Пример с двумя сообщениями.
Это — многострочный комментарий.
*/
alert('Привет');
alert('Мир');
```

> **Вложенные** комментарии `/* ... /* ... */ ... */` **не поддерживаются**.

> Горячая клавиша в редакторе — `Ctrl + /` (закомментировать строку), `Ctrl + Shift + /` (блок).

### 5.3. Строгий режим — `"use strict"`

JavaScript долго развивался без проблем совместимости: новые функции добавлялись, а старые не менялись. Но в **2009 году (ES5)** появились новые возможности, изменяющие существующие. Чтобы старый код не сломался, они по умолчанию **выключены** и включаются специальной директивой `"use strict"`.

#### Как включить

Директива должна быть **в самом начале скрипта** (или функции):

```js
"use strict";

// этот код работает по современному стандарту
```

Если перед `"use strict"` есть какой-то код, директива **не сработает** (допускаются только комментарии).

- Для скрипта: в самом верху файла.
- Для функции: в начале тела функции.

> **Отменить** `"use strict"` невозможно — раз включённый, режим остаётся.

#### Консоль браузера

В консоли разработчика `use strict` по умолчанию не применяется. Можно использовать `Shift + Enter` для ввода нескольких строк:

```js
'use strict'; <Shift+Enter для перехода на новую строку>
//  ...ваш код
<Enter для запуска>
```

#### Нужен ли он?

- **Современные конструкции** (классы и модули) включают строгий режим **автоматически**, так что отдельно писать `"use strict"` в них не нужно.
- В остальных случаях **рекомендуется** всегда его использовать — это помогает избежать скрытых ошибок.

#### Пример отличия

```js
"use strict";
x = 5; // Ошибка: x is not defined (нельзя использовать необъявленную переменную)
```

### 5.4. Переменные

**Переменная** — «именованное хранилище» для данных. Используются для хранения информации: посетителей, товаров, сообщений и т. д.

#### Объявление

Для создания переменной используются ключевые слова `let`, `const` (современные) и `var` (устаревшее).

```js
let message;       // объявили переменную
message = 'Hello'; // сохранили в неё строку

alert(message);    // покажет содержимое переменной
```

Можно совместить объявление и присвоение:

```js
let message = 'Hello!';
alert(message); // Hello!
```

Несколько переменных можно объявить в одной строке (но лучше — каждую отдельно для читаемости):

```js
let user = 'John', age = 25, message = 'Hello';
```

#### Аналогия с коробкой

Переменную можно представить как «коробку» с именем, в которую кладётся значение. Значение можно **изменить**; при изменении старое значение удаляется:

```js
let message;

message = 'Hello!';
message = 'World!'; // значение изменено
```

Можно **копировать** значение из одной переменной в другую:

```js
let hello = 'Hello world!';
let message;

message = hello; // копируем 'Hello world!' из hello в message
```

> **Повторное объявление** той же переменной через `let` — ошибка.

#### Имена переменных

Есть два ограничения:

1. Имя может содержать **только буквы, цифры, символы `$` и `_`**.
2. Первый символ **не должен быть цифрой**.

```js
let userName;
let test123;
let $ = 1;
let _ = 2;
```

- Регистр **имеет значение**: `apple` и `APPLE` — разные переменные.
- Можно использовать кириллицу, но это **не рекомендуется**.
- **Зарезервированные слова** (`let`, `class`, `return`, `function` и др.) использовать нельзя.

```js
let let = 5;    // Ошибка!
let return = 5; // Ошибка!
```

#### Правила хорошего тона

- Использовать **понятные имена**: `userName`, `shoppingCart`.
- Стиль **camelCase**: слова слитно, каждое слово с заглавной, кроме первого.
- Избегать сокращений вроде `a`, `b`, `c`, если они не очевидны.
- Имя должно максимально **точно описывать** хранимые данные.

#### Константы (`const`)

Для переменной, которая **не меняется**, используют `const`:

```js
const myBirthday = '18.04.1982';
myBirthday = '01.01.2001'; // ошибка! константу нельзя изменить
```

**Константы-«псевдонимы»** для трудно запоминаемых значений принято писать в ВЕРХНЕМ_РЕГИСТРЕ:

```js
const COLOR_RED = "#F00";
const COLOR_GREEN = "#0F0";
const COLOR_BLUE = "#00F";
const COLOR_ORANGE = "#FF7F00";

let color = COLOR_ORANGE;
alert(color); // #FF7F00
```

Заглавными буквами называют константы, значения которых известны **до** выполнения скрипта; остальные — как обычные переменные (camelCase).

#### `var` (устаревший способ)

Работает похоже на `let`, но отличается областью видимости и «всплытием». В современных скриптах **не используется**.

### 5.5. Типы данных

JavaScript — язык с **динамической типизацией**: типы существуют, но переменная не привязана к типу и может хранить значения разных типов.

```js
let message = "hello";
message = 123456; // ошибки нет
```

Всего в языке **8 типов данных**: 7 примитивных и 1 объектный.

#### Number (число)

Целые и дробные числа:

```js
let n = 123;
n = 12.345;
```

Кроме обычных чисел, есть **специальные числовые значения**:

- `Infinity` — бесконечность (например, `1 / 0`).
- `-Infinity` — отрицательная бесконечность.
- `NaN` — вычислительная ошибка (Not-a-Number).

```js
alert( 1 / 0 );             // Infinity
alert( "не число" / 2 );    // NaN
alert( NaN + 1 );           // NaN (NaN «заразен»)
```

> Математические операции в JS «безопасны» — скрипт не упадёт, максимум вернёт `NaN`.

#### BigInt

Тип для целых чисел произвольной длины (число типа `Number` безопасно хранит до 2⁵³ − 1). Создаётся добавлением `n` в конец:

```js
const bigInt = 1234567890123456789012345678901234567890n;
```

#### String (строка)

Строка должна быть заключена в кавычки. Три типа кавычек:

1. **Двойные:** `"Привет"`
2. **Одинарные:** `'Привет'`
3. **Обратные (бэктики):** `` `Привет` ``

Двойные и одинарные — «простые», разницы между ними нет.

**Обратные кавычки** позволяют встраивать выражения через `${...}`:

```js
let name = "Иван";

alert( `Привет, ${name}!` );   // Привет, Иван!
alert( `Результат: ${1 + 2}` ); // Результат: 3
```

Кроме того, они допускают **многострочные** строки.

> В JavaScript **нет** отдельного типа «символ» (char), как в некоторых языках.

#### Boolean (логический тип)

Два значения: `true` и `false`.

```js
let nameFieldChecked = true;
let ageFieldChecked = false;
```

Также получается как результат сравнений:

```js
let isGreater = 4 > 1;
alert( isGreater ); // true
```

#### null

Особый тип, имеющий единственное значение `null`. Означает «**ничего**», «**пусто**» или «**значение неизвестно**»:

```js
let age = null;
```

#### undefined

Особый тип, означающий «**значение не присвоено**». Если переменная объявлена, но ей ничего не присвоено, её значение — `undefined`:

```js
let age;
alert(age); // undefined
```

> Явно присваивать `undefined` не рекомендуется. Для «пустого» значения используют `null`.

#### Symbol

Тип для создания уникальных идентификаторов в объектах. Подробнее изучается позже.

#### Object (объект)

Особый тип. Все остальные типы называются «примитивными», потому что их значения содержат только одну вещь. **Объекты** же используются для хранения **коллекций данных** и более сложных сущностей. Изучаются позже, после примитивов.

#### Оператор `typeof`

Возвращает **строку** с названием типа аргумента. Две формы записи: `typeof x` или `typeof(x)`.

```js
typeof undefined // "undefined"

typeof 0 // "number"

typeof 10n // "bigint"

typeof true // "boolean"

typeof "foo" // "string"

typeof Symbol("id") // "symbol"

typeof Math // "object"  (1)

typeof null // "object"  (2)

typeof alert // "function"  (3)
```

Особенности:

1. `Math` — встроенный объект, поэтому `"object"`.
2. `typeof null` возвращает `"object"` — это **официально признанная ошибка** языка, оставленная для совместимости. На самом деле `null` **не** объект.
3. Функции в `typeof` выделяются отдельно (`"function"`), хотя формально это объекты.

#### Итоговая таблица

| Тип | Пример | Что хранит |
|-----|--------|-----------|
| `number` | `42`, `3.14`, `NaN` | Числа |
| `bigint` | `123n` | Большие целые |
| `string` | `"текст"` | Строки |
| `boolean` | `true`, `false` | Логические значения |
| `null` | `null` | «Пусто» |
| `undefined` | `undefined` | «Не присвоено» |
| `symbol` | `Symbol("id")` | Уникальные идентификаторы |
| `object` | `{ name: "John" }` | Коллекции, сложные структуры |

### 5.6. Взаимодействие: alert, prompt, confirm

Три функции браузера для простого взаимодействия с пользователем. Все они **модальные**: останавливают выполнение скрипта и не дают взаимодействовать со страницей, пока окно не закрыто.

> Положение окна и его внешний вид определяются браузером — изменить их нельзя.

#### `alert`

Показывает сообщение и ждёт, пока пользователь нажмёт «OK».

```js
alert("Hello");
```

#### `prompt`

Показывает окно с сообщением, полем для ввода текста и кнопками «OK» / «Отмена».

```js
result = prompt(title, [default]);
```

- `title` — текст для отображения.
- `default` — необязательное начальное значение поля ввода.

Результат:

- введённая **строка**, если нажали «OK» (или `Enter`);
- `null`, если нажали «Отмена» (или `Esc`).

```js
let age = prompt('Сколько тебе лет?', 100);

alert(`Тебе ${age} лет!`); // Тебе 100 лет!
```

> В IE при вызове `prompt` всегда нужно указывать второй аргумент (иначе в поле появится `undefined`). Лучше всегда передавать значение по умолчанию, например пустую строку `''`.

#### `confirm`

Показывает окно с вопросом и двумя кнопками: «OK» и «Отмена».

```js
result = confirm(question);
```

Результат:

- `true` — если нажали «OK»;
- `false` — в остальных случаях.

```js
let isBoss = confirm("Ты здесь главный?");

alert( isBoss ); // true, если нажата OK
```

#### Сводная таблица

| Функция | Что показывает | Что возвращает |
|---------|---------------|----------------|
| `alert(msg)` | Сообщение с кнопкой «OK» | `undefined` |
| `prompt(msg, [default])` | Поле ввода + «OK» / «Отмена» | Строка или `null` |
| `confirm(question)` | Вопрос + «OK» / «Отмена» | `true` или `false` |

#### Ограничения

1. Расположение окон определяет браузер (обычно по центру).
2. Внешний вид зависит от браузера, изменить его нельзя.

### 5.7. Преобразование типов

Чаще всего операторы и функции сами приводят значения к нужному типу. Например, `alert` автоматически превращает любое значение в строку, а математические операторы — в числа. Это называется **приведением типов**. Основных преобразований три: **строковое**, **численное** и **логическое**.

> Здесь речь о примитивах. Преобразование объектов рассматривается позже.

#### Строковое преобразование

Происходит, когда нужно строковое представление значения. Явно выполняется функцией `String(value)`:

```js
let value = true;
alert(typeof value); // boolean

value = String(value); // теперь value — строка "true"
alert(typeof value); // string
```

Для примитивов результат очевиден: `false` → `"false"`, `null` → `"null"`.

#### Численное преобразование

Происходит автоматически в математических функциях и выражениях:

```js
alert( "6" / "2" ); // 3, строки преобразуются в числа
```

Явно — функцией `Number(value)`:

```js
let str = "123";
alert(typeof str); // string

let num = Number(str); // становится числом 123
alert(typeof num); // number
```

Это удобно, когда значение приходит из текстового поля (например, из `prompt`). Если строку нельзя интерпретировать как число, результат — `NaN`:

```js
let age = Number("абвгд");
alert(age); // NaN
```

**Правила численного преобразования:**

| Значение | Результат |
|----------|-----------|
| `undefined` | `NaN` |
| `null` | `0` |
| `true` / `false` | `1` / `0` |
| Строка | Пробелы по краям обрезаются. Пустая строка → `0`. Иначе число считывается из строки, при ошибке — `NaN` |

```js
alert( Number("   123   ") ); // 123
alert( Number("123z") );      // NaN (ошибка чтения числа)
alert( Number(true) );        // 1
alert( Number(false) );       // 0
```

> `null` и `undefined` ведут себя по-разному: `null` → `0`, а `undefined` → `NaN`.

Большинство математических операторов работают так же, а вот **сложение `+`** со строкой объединяет строки.

#### Логическое преобразование

Самое простое. Происходит в логических операциях, а явно выполняется через `Boolean(value)`.

Правило:

- значения, которые интуитивно «пустые» (`0`, пустая строка, `null`, `undefined`, `NaN`), становятся `false`;
- остальные значения становятся `true`.

```js
alert( Boolean(1) );       // true
alert( Boolean(0) );       // false

alert( Boolean("привет") ); // true
alert( Boolean("") );       // false
```

> **Ловушка:** строка `"0"` — это `true`, как и строка из одного пробела `" "`. Непустая строка всегда `true`.

```js
alert( Boolean("0") ); // true
alert( Boolean(" ") ); // true
```

#### Итоги

| Преобразование | Как вызвать | Особенности |
|----------------|-------------|-------------|
| Строковое | `String(value)` | Для `false` даёт `"false"` |
| Численное | `Number(value)` | `undefined` → `NaN`, `null` → `0`, строка → число или `NaN` |
| Логическое | `Boolean(value)` | `0`, `""`, `null`, `undefined`, `NaN` → `false`, остальное → `true` |

### 5.8. Базовые операторы, математика

#### Термины

- **Операнд** — то, к чему применяется оператор. В `5 * 2` два операнда: `5` и `2`.
- **Унарный** оператор применяется к одному операнду (например, унарный минус `-x`).
- **Бинарный** оператор применяется к двум операндам (`x - y`).

#### Математические операторы

Поддерживаются: сложение `+`, вычитание `-`, умножение `*`, деление `/`, взятие остатка `%`, возведение в степень `**`.

**Остаток от деления `%`:**

```js
alert( 5 % 2 ); // 1
alert( 8 % 3 ); // 2
alert( 8 % 4 ); // 0
```

**Возведение в степень `a ** b`:**

```js
alert( 2 ** 2 ); // 4  (2 * 2)
alert( 2 ** 3 ); // 8  (2 * 2 * 2)
alert( 2 ** 4 ); // 16
```

Работает и с нецелыми числами:

```js
alert( 4 ** (1/2) ); // 2 (степень 1/2 — это квадратный корень)
alert( 8 ** (1/3) ); // 2 (степень 1/3 — кубический корень)
```

#### Сложение строк через бинарный `+`

Если хотя бы один операнд — строка, то второй тоже превращается в строку, и происходит **конкатенация**:

```js
alert( "моя" + "строка" ); // моястрока

alert( '1' + 2 ); // "12"
alert( 2 + '1' ); // "21"
```

Операции идут слева направо, поэтому порядок важен:

```js
alert( 2 + 2 + '1' ); // "41", а не "221"
```

Остальные арифметические операторы работают только с числами и приводят строки к числам:

```js
alert( 6 - '2' ); // 4
alert( '6' / '2' ); // 3
```

#### Унарный плюс `+`

Для чисел ничего не делает, а для остальных **преобразует значение в число** (как `Number(...)`, но короче):

```js
alert( +true ); // 1
alert( +"" );   // 0
```

Полезно, когда значения приходят строками:

```js
let apples = "2";
let oranges = "3";

alert( apples + oranges );   // "23" (конкатенация)
alert( +apples + +oranges ); // 5 (сложение чисел)
```

#### Приоритет операторов

Если в выражении несколько операторов, порядок задаёт **приоритет**. Выше приоритет — раньше выполнение:

1. унарные плюс и минус;
2. `**`;
3. `*` и `/`;
4. `+` и `-` (бинарные);
5. `=` (присваивание).

Поэтому унарные операторы выполняются раньше бинарных. Скобки `()` перебивают любой приоритет.

#### Присваивание `=`

Это тоже оператор: он **возвращает значение**.

```js
let a = 1;
let b = 2;

let c = 3 - (a = b + 1);

alert( a ); // 3
alert( c ); // 0
```

> Так писать не стоит: код становится трудным для понимания.

**Цепочка присваиваний** вычисляется справа налево:

```js
let a, b, c;

a = b = c = 2 + 2;

alert( a ); // 4
alert( b ); // 4
alert( c ); // 4
```

#### Сокращённая арифметика

Оператор и присваивание объединяются:

```js
let n = 2;
n += 5; // теперь n = 7 (то же, что n = n + 5)
n *= 2; // теперь n = 14 (то же, что n = n * 2)
```

Есть такие формы для всех арифметических и побитовых операторов: `/=`, `-=`, `%=`, `**=` и т. д. Приоритет у них **ниже**, чем у обычных операторов:

```js
let n = 2;

n *= 3 + 5; // сначала 3 + 5 = 8, затем n *= 8

alert( n ); // 16
```

#### Инкремент и декремент

- **Инкремент `++`** увеличивает переменную на 1.
- **Декремент `--`** уменьшает на 1.

```js
let counter = 2;
counter++; // то же, что counter = counter + 1
alert( counter ); // 3

let counter2 = 2;
counter2--; // то же, что counter2 = counter2 - 1
alert( counter2 ); // 1
```

> Применять `++` и `--` можно **только к переменным**. Запись `5++` вызовет ошибку.

Различие **префиксной** (`++counter`) и **постфиксной** (`counter++`) форм:

- префиксная возвращает **новое** значение;
- постфиксная возвращает **старое** значение (до увеличения).

```js
let counter = 1;
let a = ++counter; // префикс
alert( a ); // 2

let counter2 = 1;
let b = counter2++; // постфикс
alert( b ); // 1 (старое значение)
alert( counter2 ); // 2
```

Если результат выражения не используется, разницы между формами нет.

#### Побитовые операторы

Работают с числами на уровне их 32-битного представления: `&` (AND), `|` (OR), `^` (XOR), `~` (NOT), `<<` (сдвиг влево), `>>` (сдвиг вправо), `>>>` (беззнаковый сдвиг вправо). Используются редко.

#### Оператор запятая

Позволяет вычислить несколько выражений, разделив их запятой. Вычисляются все, а возвращается результат **последнего**:

```js
let a = (1 + 2, 3 + 4);

alert( a ); // 7 (результат 3 + 4)
```

> У запятой очень низкий приоритет, поэтому скобки здесь обязательны.

### 5.9. Операторы сравнения

Известны из математики: больше/меньше `>` `<`, больше/меньше или равно `>=` `<=`, равно `==`, не равно `!=`, строгое равенство `===` и строгое неравенство `!==`.

Результат любого сравнения — значение логического типа: `true` («да») или `false` («нет»).

```js
alert( 2 > 1 );  // true
alert( 2 == 1 ); // false
alert( 2 != 1 ); // true
```

Результат можно записать в переменную:

```js
let result = 5 > 4;
alert( result ); // true
```

#### Сравнение строк

Строки сравниваются **посимвольно** («в лексикографическом порядке»). Сравнение идёт по кодам символов Unicode.

```js
alert( 'Я' > 'А' );       // true
alert( 'Коты' > 'Кода' ); // true
alert( 'Сонный' > 'Сон' ); // true
```

Алгоритм:

1. Сравниваются первые символы строк.
2. Если они разные — результат определён по ним.
3. Если одинаковые — сравниваются вторые символы, и так далее.
4. Если одна строка закончилась, а другая нет, то более короткая меньше.

> Это не точно словарный порядок: заглавные буквы **меньше** строчных (у них меньшие коды).

#### Сравнение разных типов

Значения приводятся к **числам**:

```js
alert( '2' > 1 );   // true, строка '2' становится числом 2
alert( '01' == 1 ); // true, строка '01' становится числом 1
```

Для логических значений: `true` становится `1`, `false` — `0`.

```js
alert( true == 1 );  // true
alert( false == 0 ); // true
```

Из-за этого возможна неожиданная ситуация:

```js
let a = 0;
alert( Boolean(a) ); // false

let b = "0";
alert( Boolean(b) ); // true

alert( a == b ); // true!
```

С точки зрения JavaScript здесь всё логично: `==` приводит обе стороны к числам (`"0"` → `0`), а `Boolean()` работает по другим правилам.

#### Строгое равенство `===`

Обычное равенство `==` не отличает `0` от `false`, а пустую строку от `false`, потому что приводит операнды к числам:

```js
alert( 0 == false );  // true
alert( '' == false ); // true
```

**Строгое равенство `===`** сравнивает значения **без приведения типов**: если типы разные, результат сразу `false`.

```js
alert( 0 === false ); // false, так как типы разные
```

Аналогично `!=` и строгое неравенство `!==`.

#### Сравнение с `null` и `undefined`

**Строгое равенство:**

```js
alert( null === undefined ); // false (разные типы)
```

**Нестрогое равенство** — особое правило: эти два значения равны друг другу и **не равны** ничему другому:

```js
alert( null == undefined ); // true
```

**Математические операторы и сравнения** `< > <= >=` приводят `null` к `0`, а `undefined` — к `NaN`.

##### Странный результат: `null` и `0`

```js
alert( null > 0 );  // false (1)
alert( null == 0 ); // false (2)
alert( null >= 0 ); // true (3)
```

Причина: нестрогое равенство и операторы сравнения работают по-разному. Сравнения `>` и `>=` превращают `null` в число `0`, поэтому (3) даёт `true`, а (1) — `false`. Нестрогое же равенство `==` для `null` и `undefined` не выполняет никаких преобразований, поэтому (2) — `false`.

##### Несравнимое значение `undefined`

`undefined` нельзя сравнивать с другими значениями:

```js
alert( undefined > 0 );  // false (1)
alert( undefined < 0 );  // false (2)
alert( undefined == 0 ); // false (3)
```

- (1) и (2) — `false`, потому что `undefined` превращается в `NaN`, а любое сравнение с `NaN` даёт `false`.
- (3) — `false`, потому что `undefined` равен только `null` и самому себе.

#### Как избежать проблем

- Относиться к любому сравнению с `null`/`undefined` (кроме строгого `===`) с осторожностью.
- Не использовать `>=`, `>`, `<`, `<=` с переменными, которые могут быть `null`/`undefined`, без отдельной проверки.

### 5.10. Условное ветвление: if и тернарный оператор

Иногда нужно выполнять разные действия в зависимости от условия. Для этого есть оператор `if` и условный (тернарный) оператор `?`.

#### Оператор `if`

Вычисляет условие в скобках и, если результат `true`, выполняет блок кода:

```js
let year = prompt('В каком году появился стандарт ECMAScript-2015?', '');

if (year == 2015) alert( 'Вы правы!' );
```

Для нескольких инструкций используют фигурные скобки:

```js
if (year == 2015) {
  alert( "Правильно!" );
  alert( "Вы такой умный!" );
}
```

> Рекомендуется **всегда** использовать `{}`, даже для одной инструкции: так код легче читать и расширять.

#### Преобразование к логическому типу

Выражение в `if (...)` вычисляется и приводится к логическому типу:

- число `0`, пустая строка `""`, `null`, `undefined` и `NaN` → `false` («ложные» значения);
- остальные значения → `true` («истинные»).

```js
if (0) { // 0 — false
  ...
}

if (1) { // 1 — true
  ...
}
```

Можно передавать и заранее вычисленное логическое значение:

```js
let cond = (year == 2015); // true или false

if (cond) {
  ...
}
```

#### Блок `else`

Выполняется, если условие ложно:

```js
let year = prompt('В каком году появился стандарт ECMAScript-2015?', '');

if (year == 2015) {
  alert( 'Да вы знаток!' );
} else {
  alert( 'Как же так? Ошиблись!' );
}
```

#### Несколько условий: `else if`

```js
let year = prompt('В каком году появился стандарт ECMAScript-2015?', '');

if (year < 2015) {
  alert( 'Это слишком рано...' );
} else if (year > 2015) {
  alert( 'Это поздновато' );
} else {
  alert( 'Верно!' );
}
```

Блоков `else if` может быть сколько угодно, а последний `else` необязателен.

#### Условный оператор `?`

Позволяет записать `if...else` короче. Он **тернарный** — у него три операнда:

```js
let result = условие ? значение1 : значение2;
```

Если условие истинно, возвращается `значение1`, иначе — `значение2`:

```js
let accessAllowed = (age > 18) ? true : false;
```

Скобки вокруг условия необязательны, но улучшают читаемость. В этом конкретном примере `? true : false` лишнее: достаточно `let accessAllowed = age > 18;`.

#### Несколько операторов `?`

Цепочка `?` позволяет задать несколько вариантов:

```js
let age = prompt('Возраст?', 18);

let message = (age < 3) ? 'Здравствуй, малыш!' :
  (age < 18) ? 'Привет!' :
  (age < 100) ? 'Здравствуйте!' :
  'Какой необычный возраст!';

alert( message );
```

Она вычисляется по порядку: первое условие, при ложном — второе, и так далее; последнее значение — вариант «иначе».

#### Нетрадиционное использование `?`

Иногда `?` используют вместо `if` для выполнения разного кода:

```js
let company = prompt('Какая компания создала JavaScript?', '');

(company == 'Netscape') ?
   alert('Верно!') : alert('Неправильно.');
```

> Так писать **не рекомендуется**: `if` читается лучше. `?` стоит использовать, когда нужно **присвоить значение** в зависимости от условия.

### 5.11. Логические операторы

В JavaScript есть три логических оператора: `||` (ИЛИ), `&&` (И) и `!` (НЕ). Они могут применяться к значениям любого типа, и результат тоже может быть любого типа.

#### `||` (ИЛИ)

```js
result = a || b;
```

Классически — результат `true`, если **хотя бы один** аргумент `true`:

```js
alert( true || true );   // true
alert( false || true );  // true
alert( true || false );  // true
alert( false || false ); // false
```

Если операнд не логического типа, он приводится к нему для вычислений:

```js
if (1 || 0) { // работает как if( true || false )
  alert( 'truthy!' );
}
```

Типичное использование — в `if` для проверки нескольких вариантов:

```js
let hour = 9;

if (hour < 10 || hour > 18) {
  alert( 'Офис закрыт.' );
}
```

##### ИЛИ находит первое истинное значение

```js
result = value1 || value2 || value3;
```

Алгоритм:

1. Вычисляются операнды слева направо.
2. Каждый операнд приводится к логическому типу; если результат `true`, вычисление **останавливается** и возвращается **исходное** значение этого операнда.
3. Если все операнды ложные, возвращается **последний** из них.

```js
alert( 1 || 0 );        // 1
alert( null || 1 );     // 1
alert( null || 0 || 1 ); // 1 (первое истинное)

alert( undefined || null || 0 ); // 0 (все ложные, вернулся последний)
```

Применения:

1. **Получение первого истинного значения из списка:**

```js
let firstName = "";
let lastName = "";
let nickName = "СуперКодер";

alert( firstName || lastName || nickName || "Аноним" ); // СуперКодер
```

2. **Сокращённое вычисление.** Правый операнд вычисляется, только если левый ложный:

```js
true || alert("не напечатано");
false || alert("напечатано");
```

#### `&&` (И)

```js
result = a && b;
```

Возвращает `true`, только если **оба** аргумента истинны:

```js
alert( true && true );   // true
alert( false && true );  // false
alert( true && false );  // false
alert( false && false ); // false
```

Пример: `if (hour == 12 && minute == 30)`.

##### И находит первое ложное значение

```js
result = value1 && value2 && value3;
```

Алгоритм:

1. Вычисляются операнды слева направо.
2. Каждый приводится к логическому типу; если результат `false`, вычисление **останавливается** и возвращается **исходное** значение этого операнда.
3. Если все операнды истинны, возвращается **последний** из них.

```js
alert( 1 && 0 );      // 0
alert( 1 && 5 );      // 5
alert( null && 5 );   // null
alert( 0 && "не важно" ); // 0
```

> Приоритет `&&` **выше**, чем у `||`. Поэтому `a && b || c && d` — это `(a && b) || (c && d)`.

> Не стоит заменять `if` на `||` или `&&`: код становится менее очевидным, хотя технически это возможно.

#### `!` (НЕ)

```js
result = !value;
```

Приводит аргумент к логическому типу и возвращает **противоположное** значение:

```js
alert( !true );  // false
alert( !0 );     // true
```

**Двойное НЕ `!!`** — способ преобразовать значение к логическому типу (то же, что `Boolean(...)`):

```js
alert( !!"непустая строка" ); // true
alert( !!null );              // false
```

У `!` приоритет **выше**, чем у `&&` и `||`.

#### Приоритет логических операторов

`!` → `&&` → `||` (от высшего к низшему).

### 5.12. Оператор нулевого слияния и присваивания

В этом разделе два оператора: **`??`** (нулевое слияние) и **`??=`** (присваивание нулевого слияния).

#### Оператор `??`

Результат `a ?? b`:

- если `a` определено (не `null` и не `undefined`), то `a`;
- иначе `b`.

Эквивалентная запись без этого оператора:

```js
result = (a !== null && a !== undefined) ? a : b;
```

Обычно используется для задания **значения по умолчанию**:

```js
let user;

alert( user ?? "Аноним" ); // Аноним (user не задан)

let user2 = "Админ";

alert( user2 ?? "Аноним" ); // Админ
```

Можно строить цепочки — вернётся первое определённое значение:

```js
let firstName = null;
let lastName = null;
let nickName = "Суперкодер";

alert( firstName ?? lastName ?? nickName ?? "Аноним" ); // Суперкодер
```

#### Сравнение с `||`

Разница в том, что:

- `||` возвращает **первое истинное** значение;
- `??` возвращает **первое определённое** значение (не `null`/`undefined`).

Оператор `||` не различает `false`, `0`, пустую строку `""` и `null`/`undefined` — для него все они «ложные». Это бывает проблемой, когда `0` — допустимое значение:

```js
let height = 0;

alert( height || 100 ); // 100
alert( height ?? 100 ); // 0
```

Здесь `height || 100` считает `0` ложным и подставляет `100`, а `height ?? 100` оставляет `0`, потому что оно определено.

#### Приоритет

У `??` приоритет довольно низкий: он выше `=` и `?`, но **ниже** большинства других операторов (например, `+` и `*`). Поэтому в выражениях часто нужны скобки:

```js
let height = null;
let width = null;

// важно: используйте скобки
let area = (height ?? 100) * (width ?? 50);

alert( area ); // 5000
```

#### Запрет на использование с `||` и `&&`

По соображениям безопасности `??` нельзя использовать вместе с `||` и `&&` **без явных скобок** — это вызывает синтаксическую ошибку:

```js
let x = 1 && 2 ?? 3; // SyntaxError

let y = (1 && 2) ?? 3; // работает
alert( y ); // 2
```

#### Оператор `??=`

Присваивает значение переменной, **только если** в ней сейчас `null` или `undefined`. Запись `a ??= b` — сокращённая форма `a = a ?? b`.

```js
let a;
let b = 0;

a ??= 5;  // a было undefined → теперь 5
b ??= 10; // b определено (0) → остаётся 0

alert( a ); // 5
alert( b ); // 0
```

Похожим образом работают `||=` (присвоит, если значение ложное) и `&&=` (присвоит, если значение истинное).

#### Итоги

| Оператор | Что возвращает / делает |
|----------|--------------------------|
| `a \|\| b` | Первое истинное из `a`, `b` |
| `a && b` | Первое ложное, иначе последнее |
| `a ?? b` | `a`, если оно не `null`/`undefined`, иначе `b` |
| `a ??= b` | Записывает `b` в `a`, только если `a` — `null`/`undefined` |

### 5.13. Циклы while и for

**Циклы** нужны, чтобы повторять один и тот же участок кода несколько раз.

#### Цикл `while`

```js
while (условие) {
  // код, «тело цикла»
}
```

Пока `условие` истинно, выполняется тело цикла. Одно выполнение тела называется **итерацией**.

```js
let i = 0;
while (i < 3) {
  alert( i ); // 0, затем 1, затем 2
  i++;
}
```

Условие приводится к логическому типу, поэтому вместо `while (i != 0)` можно писать `while (i)`:

```js
let i = 3;
while (i) { // когда i станет 0, условие будет ложным и цикл остановится
  alert( i );
  i--;
}
```

> Если тело цикла состоит из одной строки, фигурные скобки можно опустить: `while (i) alert(i--);`.

#### Цикл `do...while`

Сначала выполняется тело, и только потом проверяется условие. Поэтому тело выполнится **хотя бы один раз**:

```js
do {
  // тело цикла
} while (условие);
```

```js
let i = 0;
do {
  alert( i );
  i++;
} while (i < 3);
```

Используйте эту форму, когда тело нужно выполнить хотя бы раз независимо от условия.

#### Цикл `for`

Самый часто используемый цикл:

```js
for (начало; условие; шаг) {
  // тело цикла
}
```

```js
for (let i = 0; i < 3; i++) { // 0, 1, 2
  alert(i);
}
```

| Часть | Пример | Когда выполняется |
|-------|--------|-------------------|
| начало | `let i = 0` | Один раз при входе в цикл |
| условие | `i < 3` | Перед каждой итерацией; если `false`, цикл останавливается |
| тело | `alert(i)` | Пока условие истинно |
| шаг | `i++` | После тела на каждой итерации |

**Встроенное объявление переменной.** Переменная `i`, объявленная в `for (let i...)`, видна только внутри цикла. Можно объявить её заранее, тогда она останется доступной и после цикла:

```js
let i = 0;
for (i = 0; i < 3; i++) {
  alert(i);
}
alert( i ); // 3, переменная доступна после цикла
```

**Пропуск частей `for`.** Любую часть можно опустить:

```js
let i = 0;
for (; i < 3; i++) { // нет «начала»
  alert( i );
}
```

Если опустить всё, получится бесконечный цикл:

```js
for (;;) {
  // будет выполняться вечно
}
```

> Две точки с запятой `;;` обязательны, иначе будет синтаксическая ошибка.

#### Прерывание цикла: `break`

Обычно цикл завершается, когда условие станет ложным. Но выйти можно в любой момент директивой `break`:

```js
let sum = 0;

while (true) {
  let value = +prompt("Введите число", '');

  if (!value) break; // (*)

  sum += value;
}
alert( 'Сумма: ' + sum );
```

Директива `break` в строке `(*)` срабатывает, если пользователь ввёл пустую строку или отменил ввод, и цикл завершается.

#### Переход к следующей итерации: `continue`

Это «облегчённая» версия `break`: она не останавливает весь цикл, а прерывает **текущую итерацию** и запускает следующую (если условие истинно).

```js
for (let i = 0; i < 10; i++) {

  // если true, пропустить оставшуюся часть тела цикла
  if (i % 2 == 0) continue;

  alert(i); // 1, затем 3, 5, 7, 9
}
```

> Вместо вложенного `if` в теле цикла часто удобнее использовать `continue`: так код проще читать.

> **Нельзя** использовать `break` и `continue` справа от оператора `?`. Конструкции, не являющиеся выражениями, там не допускаются:
>
> ```js
> (i > 5) ? alert(i) : continue; // continue здесь запрещён
> ```

#### Метки для `break` и `continue`

Иногда нужно выйти сразу из **нескольких вложенных циклов**. Для этого используют **метку** — идентификатор с двоеточием перед циклом:

```js
outer: for (let i = 0; i < 3; i++) {

  for (let j = 0; j < 3; j++) {

    let input = prompt(`Значение на координатах (${i},${j})`, '');

    // если пустая строка или Отмена, то выйти из обоих циклов
    if (!input) break outer; // (*)

    // сделать что-нибудь со значением...
  }
}
alert('Готово!');
```

`break outer` ищет метку `outer` и прерывает именно этот цикл. Аналогично работает `continue outer`: он переходит к следующей итерации помеченного цикла.

> Метки позволяют передавать управление только вверх по вложенности. Прыгнуть на произвольное место кода нельзя.

### 5.14. Конструкция `switch`

Заменяет несколько проверок `if` и даёт более наглядный способ сравнить значение с несколькими вариантами.

#### Синтаксис

```js
switch(x) {
  case 'value1':  // if (x === 'value1')
    ...
    [break]

  case 'value2':  // if (x === 'value2')
    ...
    [break]

  default:
    ...
    [break]
}
```

- Значение `x` сравнивается со значениями из `case` через **строгое равенство** (`===`).
- Если совпадение найдено, выполняется код, начиная с этого `case`, до ближайшего `break` (или до конца `switch`).
- Если совпадений нет, выполняется код ветки `default` (если она есть).

#### Пример

```js
let a = 2 + 2;

switch (a) {
  case 3:
    alert( 'Маловато' );
    break;
  case 4:
    alert( 'В точку!' );
    break;
  case 5:
    alert( 'Перебор' );
    break;
  default:
    alert( "Нет таких значений" );
}
```

Здесь выведется `В точку!`, потому что `a === 4`.

#### Что будет без `break`

Если `break` нет, выполнение продолжится в **следующем** `case` без проверки условий:

```js
let a = 2 + 2;

switch (a) {
  case 3:
    alert( 'Маловато' );
  case 4:
    alert( 'В точку!' );
  case 5:
    alert( 'Перебор' );
  default:
    alert( "Нет таких значений" );
}
```

В этом примере подряд выполнятся три `alert`: «В точку!», «Перебор» и «Нет таких значений».

> Любое выражение может быть аргументом `switch` и `case`.

#### Группировка `case`

Несколько вариантов, выполняющих один и тот же код, можно объединять:

```js
let a = 3;

switch (a) {
  case 4:
    alert('Правильно!');
    break;

  case 3: // (*) группируем оба case
  case 5:
    alert('Неправильно!');
    alert("Может, вам посетить урок математики?");
    break;

  default:
    alert('Результат странный. Честно.');
}
```

#### Тип имеет значение

Сравнение в `switch` **строгое**, значения должны быть одного типа:

```js
let arg = prompt("Введите число?", '');

switch (arg) {
  case '0':
  case '1':
    alert( 'Один или ноль' );
    break;

  case '2':
    alert( 'Два' );
    break;

  case 3:
    alert( 'Никогда не выполнится!' ); // prompt возвращает строку, а не число
    break;
  default:
    alert( 'Неизвестное значение' );
}
```

Здесь `prompt` возвращает строку, поэтому `case 3` (число) никогда не совпадёт.

### 5.15. Функции

**Функции** позволяют не повторять один и тот же код в разных местах. Они — главные «строительные блоки» программы. Примеры встроенных функций: `alert(message)`, `prompt(message, default)`, `confirm(question)`.

#### Объявление функции

```js
function showMessage() {
  alert( 'Всем привет!' );
}
```

Структура: ключевое слово `function`, **имя функции**, список **параметров** в скобках (в примере пуст) и **тело** в фигурных скобках.

Вызов — по имени со скобками:

```js
showMessage();
showMessage();
```

Благодаря функции код пишется один раз, а используется многократно. Если понадобится изменить сообщение, правка нужна только в одном месте.

#### Локальные переменные

Переменная, объявленная внутри функции, видна **только внутри** этой функции:

```js
function showMessage() {
  let message = "Привет, я JavaScript!"; // локальная переменная

  alert( message );
}

showMessage(); // Привет, я JavaScript!

alert( message ); // ошибка: переменная message недоступна снаружи
```

#### Внешние переменные

Функция может обращаться к внешним переменным и менять их:

```js
let userName = 'Вася';

function showMessage() {
  let message = 'Привет, ' + userName;
  alert(message);
}

showMessage(); // Привет, Вася
```

```js
let userName = 'Вася';

function showMessage() {
  userName = "Петя"; // (1) изменяем значение внешней переменной

  let message = 'Привет, ' + userName;
  alert(message);
}

alert( userName ); // Вася, до вызова функции

showMessage();

alert( userName ); // Петя, значение изменено
```

Внешняя переменная используется, только если нет локальной с тем же именем. Если внутри функции объявлена переменная с таким же именем, она **«затеняет»** внешнюю:

```js
let userName = 'Вася';

function showMessage() {
  let userName = "Петя"; // объявляем локальную переменную

  let message = 'Привет, ' + userName; // Петя
  alert(message);
}

showMessage();

alert( userName ); // Вася, не изменилась
```

> **Глобальные переменные** — это переменные, объявленные вне функций. Хорошая практика — свести их использование к минимуму. Современный код содержит мало глобальных переменных, а нужные функции получают данные через параметры.

#### Параметры

Через параметры функции можно передавать произвольные данные:

```js
function showMessage(from, text) { // параметры: from, text
  alert(from + ': ' + text);
}

showMessage('Аня', 'Привет!'); // Аня: Привет!
showMessage('Аня', "Как дела?"); // Аня: Как дела?
```

Значения, переданные при вызове (`'Аня'`, `'Привет!'`), называются **аргументами**. Они **копируются** в локальные переменные функции.

```js
function showMessage(from, text) {
  from = '*' + from + '*'; // немного украсим "from"
  alert( from + ': ' + text );
}

let from = "Аня";

showMessage(from, "Привет"); // *Аня*: Привет

// значение "from" осталось прежним, функция изменила локальную копию
alert( from ); // Аня
```

#### Значения по умолчанию

Если аргумент не передан, его значение становится `undefined`:

```js
showMessage("Аня"); // Аня: undefined
```

Можно задать значение по умолчанию прямо в объявлении через `=`:

```js
function showMessage(from, text = "текст не добавлен") {
  alert( from + ": " + text );
}

showMessage("Аня"); // Аня: текст не добавлен
```

Значением по умолчанию может быть любое выражение, даже вызов другой функции. Оно вычисляется **при каждом вызове**, если аргумент не передан.

**Альтернативные способы задать значение по умолчанию** внутри тела:

```js
function showMessage(text) {
  // ...
  if (text === undefined) { // если параметр отсутствует
    text = 'пустое сообщение';
  }
  alert(text);
}
```

Или с помощью `||` или `??`:

```js
function showMessage(text) {
  // если значение text ложное или undefined, присвоить ''
  text = text || 'пусто';
  // ...
}
```

#### Возврат значения

Функция может вернуть результат с помощью `return`:

```js
function sum(a, b) {
  return a + b;
}

let result = sum(1, 2);
alert( result ); // 3
```

- `return` может находиться в любом месте функции. Как только он выполнился, функция завершается, а значение возвращается в вызывающий код.
- Возможно несколько `return` в одной функции:

```js
function checkAge(age) {
  if (age >= 18) {
    return true;
  } else {
    return confirm('А родители разрешили?');
  }
}
```

- Можно использовать `return` без значения — функция сразу завершится.
- Если `return` нет или он пустой, функция возвращает `undefined`.

> **Не добавляйте перевод строки между `return` и значением.** JavaScript автоматически подставит `;` после `return`, и функция вернёт `undefined`. Если нужно разбить длинное выражение на несколько строк, открывающая скобка должна быть на той же строке, что и `return`:
>
> ```js
> return (
>   some + long + expression
>   + or +
>   whatever * f(a) + f(b)
> )
> ```

#### Выбор имени функции

Функция — это **действие**, поэтому её имя обычно **глагол**, кратко описывающий, что она делает. Часто используют префиксы:

| Префикс | Значение | Примеры |
|---------|----------|---------|
| `show…` | Показать что-то | `showMessage` |
| `get…` | Вернуть значение | `getAge` |
| `calc…` | Вычислить | `calcSum` |
| `create…` | Создать | `createForm` |
| `check…` | Проверить и вернуть логическое значение | `checkPermission` |

#### Функции должны быть короткими и делать одну вещь

- Одна функция — **одно действие**. Если нужно два, лучше создать две функции.
- Короткие функции проще тестировать, отлаживать и понимать. Иногда выделение отдельной функции делает код самодокументируемым.
- Функцию, которая делает слишком много, стоит разбить на несколько.

### 5.16. Function Expression

В JavaScript функция — это особый **вид значения**, а не языковая конструкция. Поэтому есть два способа её создания.

#### Function Declaration (объявление)

```js
function sayHi() {
  alert( "Привет" );
}
```

#### Function Expression (функциональное выражение)

```js
let sayHi = function() {
  alert( "Привет" );
};
```

Функция создаётся и записывается в переменную. В конце ставится `;`, потому что это обычное присваивание значения, а не блок кода.

#### Функция — это значение

Можно вывести её код:

```js
function sayHi() {
  alert( "Привет" );
}

alert( sayHi ); // выведет код функции (но не вызовет её)
```

Функцию можно **скопировать** в другую переменную:

```js
function sayHi() {   // (1) создаём
  alert( "Привет" );
}

let func = sayHi;    // (2) копируем

func(); // Привет     // (3) вызываем копию
sayHi(); // Привет    //     оригинал тоже работает
```

Скобки `()` в `let func = sayHi` не ставятся: иначе в переменную запишется **результат** вызова, а не сама функция.

#### Функции-«колбэки» (callback)

**Колбэк** — функция, которая передаётся другой функции и вызывается позже по необходимости.

```js
function ask(question, yes, no) {
  if (confirm(question)) yes()
  else no();
}

function showOk() {
  alert( "Вы согласны." );
}

function showCancel() {
  alert( "Вы отменили выполнение." );
}

// использование: функции showOk, showCancel передаются как аргументы ask
ask("Вы согласны?", showOk, showCancel);
```

Те же функции можно записать короче, **анонимно** — без имени, прямо в месте вызова:

```js
function ask(question, yes, no) {
  if (confirm(question)) yes()
  else no();
}

ask(
  "Вы согласны?",
  function() { alert("Вы согласились."); },
  function() { alert("Вы отменили выполнение."); }
);
```

Такие функции доступны только внутри `ask`, потому что не записаны ни в какие переменные.

#### Function Expression и Function Declaration: различия

**1. Синтаксис.**

```js
// Function Declaration: функция в основном потоке кода
function sum(a, b) {
  return a + b;
}

// Function Expression: функция — часть выражения (присваивания)
let sum = function(a, b) {
  return a + b;
};
```

**2. Время создания.**

- **Function Expression** создаётся, когда выполнение доходит до неё.
- **Function Declaration** создаётся заранее, при подготовке скрипта к выполнению, и доступна **во всём скрипте**, даже выше своего объявления.

```js
sayHi("Вася"); // Привет, Вася

function sayHi(name) {
  alert( `Привет, ${name}` );
}
```

А с Function Expression так не получится:

```js
sayHi("Вася"); // ошибка!

let sayHi = function(name) {  // (*) магии больше нет
  alert( `Привет, ${name}` );
};
```

**3. Область видимости в строгом режиме.** Function Declaration, объявленная в блоке `{...}`, видна только внутри этого блока:

```js
let age = prompt("Сколько вам лет?", 18);

// условно объявляем функцию
if (age < 18) {
  function welcome() {
    alert("Привет!");
  }
} else {
  function welcome() {
    alert("Здравствуйте!");
  }
}

// ...использовать её снаружи блока не получится
welcome(); // Ошибка: welcome is not defined
```

Чтобы функция была видна снаружи, используют Function Expression и присваивают её внешней переменной:

```js
let age = prompt("Сколько вам лет?", 18);

let welcome;

if (age < 18) {
  welcome = function() {
    alert("Привет!");
  };
} else {
  welcome = function() {
    alert("Здравствуйте!");
  };
}

welcome(); // теперь всё работает
```

Или ещё короче — через оператор `?`:

```js
let welcome = (age < 18) ?
  function() { alert("Привет!"); } :
  function() { alert("Здравствуйте!"); };

welcome(); // теперь всё в порядке
```

#### Что выбрать?

Как правило, если нужно объявить функцию, сначала рассматривайте синтаксис **Function Declaration**. Он даёт больше свободы в организации кода: функции можно вызывать раньше, чем они объявлены, и код читается проще. **Function Expression** используют, когда Declaration не подходит по каким-то причинам.

### 5.17. Стрелочные функции, основы

Есть ещё один, очень простой и краткий синтаксис создания функций, который часто лучше Function Expression. Он называется **стрелочные функции**.

#### Синтаксис

```js
let func = (arg1, arg2, ..., argN) => expression;
```

Создаётся функция `func` с аргументами `arg1..argN`, которая вычисляет `expression` справа и возвращает результат. То же самое, что:

```js
let func = function(arg1, arg2, ..., argN) {
  return expression;
};
```

Пример:

```js
let sum = (a, b) => a + b;

/* Более короткая форма для:

let sum = function(a, b) {
  return a + b;
};
*/

alert( sum(1, 2) ); // 3
```

#### Особые случаи

**Один аргумент** — скобки можно опустить:

```js
let double = n => n * 2;
// примерно то же, что и: let double = function(n) { return n * 2 }

alert( double(3) ); // 6
```

**Нет аргументов** — скобки пустые, но обязательны:

```js
let sayHi = () => alert("Привет!");

sayHi();
```

Стрелочные функции можно использовать так же, как и Function Expression. Например, для динамического создания функции:

```js
let age = prompt("Сколько вам лет?", 18);

let welcome = (age < 18) ?
  () => alert('Привет!') :
  () => alert("Здравствуйте!");

welcome();
```

#### Многострочные стрелочные функции

Если нужно несколько выражений или инструкций, используйте **фигурные скобки** и обязательный `return`:

```js
let sum = (a, b) => {  // фигурная скобка открывает тело
  let result = a + b;
  return result; // при фигурных скобках нужен явный return
};

alert( sum(1, 2) ); // 3
```

> Без `return` при фигурных скобках функция вернёт `undefined`.

#### Сравнение трёх способов

| Способ | Пример |
|--------|--------|
| Function Declaration | `function sum(a, b) { return a + b; }` |
| Function Expression | `let sum = function(a, b) { return a + b; };` |
| Стрелочная функция | `let sum = (a, b) => a + b;` |

> Подробнее о стрелочных функциях (например, об особенностях `this`) рассказывается позже. Пока достаточно их основ: для коротких действий и колбэков они очень удобны.

### 5.18. Особенности JavaScript

Краткое повторение того, что было изучено в разделе «Основы JavaScript», с акцентом на тонкие моменты.

#### Структура кода

- Инструкции разделяются точкой с запятой; перевод строки обычно её заменяет, но не всегда, поэтому `;` лучше ставить.
- Блоки кода объединяются фигурными скобками `{...}`.
- Комментарии: однострочные `// ...` и многострочные `/* ... */`.

#### Строгий режим

Чтобы включить все возможности современного языка, нужна директива `"use strict"` **в самом начале** скрипта или функции. Классы и модули включают строгий режим автоматически.

#### Переменные

Объявляются через `let`, `const` (константа, не меняется), также возможен устаревший `var`. Имя может содержать буквы, цифры, `$` и `_`, но не начинаться с цифры. JavaScript — язык с **динамической типизацией**: переменная может хранить значения разных типов.

#### Типы данных

Восемь типов:

- `number` — для целых и дробных чисел (включая `NaN`, `Infinity`);
- `bigint` — для целых чисел произвольной длины;
- `string` — строки;
- `boolean` — `true` / `false`;
- `null` — тип с единственным значением «пусто»;
- `undefined` — «не присвоено»;
- `symbol` — уникальные идентификаторы;
- `object` — сложные структуры данных.

Оператор `typeof` возвращает тип значения; для `null` он вернёт `"object"` (это ошибка языка), а для функции — `"function"`.

#### Взаимодействие с пользователем

`prompt(question, default)` — спросить, `confirm(question)` — подтвердить, `alert(message)` — показать сообщение. Все они **модальные**: приостанавливают выполнение скрипта.

#### Операторы

- **Арифметические:** `+ - * / % **`. Бинарный `+` соединяет строки, а унарный `+` преобразует значение в число.
- **Присваивание:** простое `a = b` и составное `a *= 2`.
- **Побитовые:** работают с 32-битными целыми числами.
- **Условный:** `cond ? resultA : resultB`.
- **Логические:** `||`, `&&` (с «короткой» схемой вычисления; возвращают значение, на котором остановились), `!`.
- **Нулевое слияние:** `a ?? b`, где `b` подставляется, если `a` — `null` или `undefined`.
- **Сравнение:** нестрогое `==` приводит типы, поэтому `0` и `false` равны. Лучше использовать строгие `===` и `!==`.
- Особое поведение `null` и `undefined`: они равны друг другу (`==`) и не равны ничему другому.
- Операторы `>`, `<` и подобные приводят `null` к `0`, а `undefined` к `NaN`.

#### Циклы

```js
while (condition) {
  ...
}

do {
  ...
} while (condition);

for (let i = 0; i < 10; i++) {
  ...
}
```

- Переменная, объявленная в `for(let...)`, видна только внутри цикла. Можно объявить заранее.
- Директивы `break` / `continue` позволяют выйти из цикла или перейти к следующей итерации. Для выхода из нескольких вложенных циклов используют метки.
- Позже появятся циклы `for (key in obj)` для перебора свойств объекта и `for (value of iterable)` для перебора коллекций.

#### Конструкция `switch`

Заменяет несколько `if`. Использует **строгое сравнение** `===`.

#### Функции

Три способа создания:

```js
// 1. Function Declaration: функция в основном потоке кода
function sum(a, b) {
  let result = a + b;

  return result;
}

// 2. Function Expression: функция как часть выражения
let sum = function(a, b) {
  let result = a + b;

  return result;
};

// 3. Стрелочные функции
// выражение справа
let sum = (a, b) => a + b;

// многострочный код: нужен явный return
let sum = (a, b) => {
  // ...
  return a + b;
}

// без аргументов
let sayHi = () => alert("Привет");

// с одним аргументом
let double = n => n * 2;
```

- У функций могут быть **локальные переменные**: объявленные внутри функции или в списке параметров. Они видны только внутри функции.
- Параметры могут иметь **значения по умолчанию**: `function sum(a = 1, b = 2) {...}`.
- Функции всегда что-то возвращают. Если нет `return`, результат — `undefined`.

#### Что дальше

Это лишь краткий список особенностей JavaScript, которые нужно знать на базовом уровне. Дальше в учебнике идёт углублённое изучение: объекты, массивы, замыкания, классы, асинхронность, работа с DOM и многое другое.

## Вывод

- JavaScript подключается в HTML через `<script>` (внутри или как внешний файл `src`).
- Инструкции разделяются `;`, комментарии — `//` и `/* */`.
- `"use strict"` включает современный режим работы языка.
- Переменные объявляются через `let` и `const` (`var` — устаревший).
- Есть 8 типов данных; тип проверяется оператором `typeof`.
- Для простого диалога с пользователем есть `alert`, `prompt`, `confirm`.
- Преобразования типов: `String()`, `Number()`, `Boolean()`; `"0"` и `" "` при логическом приведении — `true`.
- Бинарный `+` со строкой склеивает строки, унарный `+` превращает значение в число.
- Для сравнения без приведения типов используют `===` и `!==`; `null == undefined`, но `null` и `undefined` ни с чем другим не равны.
- Ветвление: `if / else if / else` и тернарный оператор `условие ? a : b`.
- `||` возвращает первое истинное, `&&` — первое ложное, `!` инвертирует; приоритет `!` > `&&` > `||`.
- `??` возвращает первое определённое значение (не `null`/`undefined`), `??=` присваивает только при `null`/`undefined`.
- Циклы: `while`, `do...while`, `for`; `break` прерывает цикл, `continue` переходит к следующей итерации, метки позволяют выйти из вложенных циклов.
- `switch` сравнивает значения строго (`===`); без `break` выполнение «проваливается» в следующий `case`.
- Функции объявляются тремя способами: Function Declaration, Function Expression и стрелочная функция; без `return` функция возвращает `undefined`.
- Function Declaration доступна во всём скрипте ещё до объявления, Function Expression — только после того, как выполнение дойдёт до неё.
- Параметры можно задавать со значением по умолчанию; переменные внутри функции локальны и «затеняют» внешние с тем же именем.
